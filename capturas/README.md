# Capturas reais

Capturas do protótipo executado no Chromium do ambiente, não mockups gerados. `*-desktop.png`: viewport de 1440 × 1000; `*-mobile.png`: viewport de 390 × 844; escala 1. As páginas completas podem ser mais altas do que o viewport. `primeiro-ecra-*` mostra apenas o primeiro ecrã.

Repetir, com o servidor local ativo e as ferramentas de desenvolvimento disponíveis:

```sh
python3 tools/capture.py
```

Os layouts de 360 e 768 px foram também verificados nos testes; estas capturas são uma seleção para apresentação. As imagens de equipamento e da costa dentro das páginas continuam a ser recursos conceptuais gerados por IA, conforme o aviso do próprio protótipo.
